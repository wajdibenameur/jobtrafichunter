# Vérification des sources

Créer `<connector>.md` lors de l'étude du connecteur avec le modèle ci-dessous.
Un fichier documentaire ne suffit pas à autoriser son activation : la vérification
doit aussi être enregistrée dans JobSource et contrôlée à l'exécution.

## Modèle

- Source / connecteur : à renseigner.
- Statut initial : UNVERIFIED ; collecte automatisée désactivée.
- URL officielle de l'API ou du feed : à vérifier.
- Méthode d'accès : public, clé, OAuth ou partenariat ; accès disponible : inconnu.
- Documentation officielle consultée : liens et date réelle de consultation.
- Conditions d'utilisation : lien, date de revue et éléments probants.
- Robots.txt : URL, date et résultat ; ne remplace pas l'examen des conditions.
- Stockage, attribution et redistribution autorisés : à établir.
- Limites de débit, cache et Retry-After : à établir.
- Relecteur et décision : à renseigner.
- Prochaine revue : au plus tard 90 jours après la vérification.
- Tests sur fixtures et erreurs typées : commande et résultat réels.
- Repli si permission incertaine : lien de recherche et import manuel.

Aucune source n'a encore été vérifiée ou déclarée PERMITTED dans ce projet.
